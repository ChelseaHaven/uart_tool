# 协议使用与二进制配置

## 入口与数据流

在接收区的“数据协议”下拉框选择：

- **原始数据**：不解析，原始数据照常接收。
- **数字文本（CSV）**：每行一组逗号分隔的数字。
- **键值文本（字典）**：每行一组 `名称:数值`，用逗号分隔。
- **自定义二进制**：按已保存的配置组帧和提取字段；点击 **编辑协议** 修改。

解析从选择后新到达的数据开始，不回放原始日志。切换协议会重置解析状态；清空原始数据及成功重连也会清空解析计数和半帧。保存正在使用的二进制配置会重置解析状态，但保留原始日志和原始接收计数。配置会自动保存，协议选择仍默认原始数据。

解析页显示当前命令最近一帧的字段、数值、类型、项数和字节数，以及有效帧数、错误帧数、丢弃字节数、最近错误。没有做波形绘制或帧历史导出。数值数组最多显示前 64 项预览，原始字节显示前 128 字节预览，均标注实际总数；底层字段保留完整值。

三个模式共用暂停、清空和复制选中工具栏；只有原始数据模式提供自动滚动，CSV 和二进制保持当前查看位置。原始数据模式显示文本／HEX；CSV 和二进制模式只显示解析结果，不显示原始日志。暂停只冻结显示，接收、解析与计数继续，恢复后显示最新帧。

## 数字文本

下位机发送示例：

```text
1.2,-3.4,5.6\n
```

这里的 `\n` 表示真实换行字节 0A，不是反斜杠和字母 n。CRLF 也支持，跨多次读取的一行会自动拼接。支持负数、小数和科学计数法，一行生成一帧，依次显示为 CH1、CH2 等。

空行忽略。非数字、缺失项、NaN/Inf 会使整行报错；一行最多 128 项、8192 字节。过长的行丢弃至下一个换行，后续有效行可继续解析。

## 键值文本（字典）

发送示例（无需引号）：

```c
printf("awa:2.0,  aaa:3\n");
printf("温度:25.5, 转速:-1200, 电流:1.2e-3\n");
```

逗号分隔字段，冒号分隔名称与数值，每组用换行结束。名称和数值两侧的空格忽略，支持 CRLF、跨批次接收和多个连续行；字段卡片按首次出现的顺序排列。每行只更新其中出现的字段，其他卡片和曲线保留。曲线只为实际收到的字段添加采样点，XY 图仍使用同一行里的成对值。CSV 录制按实际收到的字段写入，缺项留空。

数值支持正负整数、小数和科学计数法，内部按 float64 解析；显示时可能省略末尾的零，如 2.0 显示为 2。空行忽略。每行上限 8192 字节、128 个字段，名称最多 64 个字符且不得为空或重复。不支持嵌套字典、数组、字符串值或 NaN/Inf。格式错误整行丢弃，过长行丢弃至下一个换行后继续；解析器只缓存未完成的一行。实时卡片和曲线最多保留前 128 个不同字段，清空、重新连接或换协议后重新累计。

## 二进制编辑器

“编辑协议”将模板管理与帧结构放在同一页面；帧头、长度、命令字、公共字段、数据区、校验和帧尾按模块排列，数据字段直接在数据区模块内编辑。字段位置、帧长和校验结果位置自动计算，只有特殊校验的覆盖范围需要手填起止位置。所有长度单位均为字节。载入模板只改变草稿；“应用并关闭”才更新正在使用的配置。

### 简洁配置（推荐）

新设备在“编辑协议”中点击 **新建**，输入模板名称后配置帧结构并保存。通过“添加模块”按发送顺序添加长度、命令字、公共字段（如序号）、数据区、校验、保留字节和固定帧尾，用上下箭头调整顺序。数据区也支持删除、重新添加；可以添加多个命令字和多个数据区，保存时至少需要一个数据区。在其内部直接添加字段并配置名称、类型、数量和字节序；位置和帧长由 Qt Core 层统一计算，不需要填写偏移。已有模板也在同一页面中编辑。

长度字段仍只设置一次，放在第一个数据区前；长度和前置命令字可交换顺序，宽度为 1／2／4 字节，分别选择大小端。长度默认表示从第一个数据区到最后一个数据区末尾的字节数，包含中间的命令字、公共字段和校验；若设备的长度包含数据区后的校验、保留字节和固定帧尾，勾选“包含数据区后的全部字节”。选择整帧字节数时也须按设备约定设置这个开关。

校验作为帧中的一个部分添加，可以在数据区前或后，也可以添加多条。结果位置随结构自动计算，默认计算从帧头到该校验之前的全部字节，也可选择只计算数据区或指定范围。选择 SUM8、SUM16、XOR8、CRC-16/MODBUS、CRC-16/CCITT-FALSE、CRC-32/ISO-HDLC 等预设不必输入 CRC 参数。另有标准 CRC-8/SMBUS、CRC-8/MAXIM-DOW 及自定义 CRC。工程专用校验只使用自定义参数，不作为通用预设。关闭规则保留其字节；删除结构中的校验部分才移除其字节。

一个模板可以配置多处命令字，每处可设置多个命令值，每个命令值拥有独立的数据字段。数据区归属于前面最近的命令字，前面没有命令字时为公共数据区；多个数据区可属于同一处命令字。在帧结构的“命令字”部分，通过下拉框选择当前编辑的命令；点击“添加命令”输入新命令值和名称，数据区直接显示所选命令的字段；切换命令会保留各自的编辑草稿。不再使用外层“数据类型”下拉框或多消息编辑区。前面各组命令的数据长度必须保持相同；最后一组可在有长度字段时使用不同长度。变长数组只允许放在最后一个数据区末尾。多数据区结果名称自动带“数据区N.”前缀，允许各区使用相同字段名。

单命令结构在接收页用“接收命令”下拉框选择当前处理项；多模块结构按每处命令字提供独立下拉框，只有全部命令值符合所选组合的整帧才解析显示。只解析和显示该命令，其他命令帧跳过，不在后台更新缓存；切换命令时清空旧结果、半帧及计数，从新收到的数据开始。未知命令正常跳过，不计为解析错误；清空、重连和切换协议会清空各命令的缓存。查看选择不单独持久化。模板仍是一个 JSON 文件，不拆文件，不创建备份。

目前通用结构仍要求 1～16 字节的帧头，最多 24 个结构部分，最后一个数据区后的全部字节最多 16 字节。固定 HEX 帧尾用于验证由帧长确定的末尾字节，不是扫描分隔符来决定帧长；尚不支持只有结束分隔符的流协议、字节转义、任意长度运算或脚本算法。

### 外置模板库

模板分为“内置模板”和“我的模板”。内置的简单固定帧、简单变长帧、多段命令帧从 Qt 只读资源加载，无法删除或覆盖。用户修改后保存为个人副本。新建、导入和基于内置模板创建的配置统一进入“我的模板”，每个是一个独立 UTF-8 JSON 文件，目录显示在编辑器中。网球机器人协议属于个人模板，不作为内置通用示例。Linux 默认目录为 `~/.local/share/UartTool/UART Tool/protocol-templates/`，其他平台由 Qt 的 AppDataLocation 决定。

- **新建**：开始新的协议草稿，填写名称和结构后保存到我的模板。
- **保存模板**：更新当前个人模板，名称变更即重命名；未选择模板或选中内置模板时创建个人副本。
- **另存为**：输入新名称，创建独立模板，不覆盖原模板。
- **导出**：把当前草稿导出为 JSON，可发送给其他用户或复制到 Windows。
- **导入**：验证 JSON 格式、版本和协议规则后复制到模板库，并载入草稿。同名会自动加序号；不会覆盖已有模板。
- **删除**：仅个人模板可用，确认后删除选中模板的文件；当前草稿和正在接收的配置保留。
- **刷新**：读取外部修改或增删的 JSON 文件。无效文件会提示原因，不会作为有效模板载入。

内置模板始终随软件存在，不再复制到用户目录。旧版本未修改的通用起步文件不再重复显示；已修改的文件和网球协议保留在我的模板。个人模板删除后不会自动补回。模板文件采用 `format: uart-tool.binary-protocol`、`version: 1`、`id`、`name`、`configuration`；结构、字段、算法名称和 CRC 参数都是数据，不加载脚本或代码。单文件上限 2 MiB，保存使用原子替换。文件名使用稳定标识，显示名称可自由修改。

保存／导入／导出／删除模板不会改变当前解析器。当前应用配置仍保存为会话快照，模板文件可独立管理。

### 帧头与帧长

- 帧头是 1～16 字节的 HEX，例如 `AA 55`，可包含空格。
- 固定帧：不添加长度字段，总长度根据所有部分自动计算。
- 变长帧：添加长度字段，选择宽度（1/2/4 字节无符号整数）、大小端和长度含义。偏移及数据区起点自动计算。
- 长度含义选“数据区字节数”时：整帧字节数 = 数据区起点 + 长度值 + 未计入长度的校验字节数。
- 长度含义选“整帧字节数”时：整帧字节数 = 长度值 + 未计入长度的校验字节数。
- “包含数据区后的全部字节”开启时，不再额外补加校验宽度。
- 最大帧长默认 4096，允许 1～65536，用来限制异常长度导致的等待和内存占用。长度值超过上限时重新搜索帧头。

数据区起点必须在长度字段之后；数据字段不能覆盖帧头、长度字段或末尾校验。数据字段按顺序自动排列；需要跳过的字节使用 padding 占位，不输出解析值。旧数据字段之间的空隙载入时会显式转换成保留字节。

### 字段

支持 uint8/int8、uint16/int16、uint32/int32、uint64/int64、float32、float64、bytes 和保留字节 padding。浮点采用 IEEE 754 表示。类型决定每项宽度，固定数组使用“数量”决定项数；bytes 的数量表示字节数。

字段可单独设置大小端。字段名不能为空或重复，最多 64 个字段。固定数量范围是 1～4096。

**剩余数值数组／剩余字节（变长）**仅允许用于最后一个字段：从字段偏移一直读取到校验字节之前。数值区大小必须能被类型宽度整除，最多 4096 项；bytes 允许读取至最大帧长边界。变长区可以为空。

当前不支持位字段、字符串编码选择、多层嵌套结构、仅靠帧尾分隔符决定帧长或任意长度运算表达式。新增这些功能应扩展协议模块，不放进串口驱动。

### 校验

校验只在帧结构的校验模块中管理，结果位置跟随结构自动计算，支持：

| 算法 | 校验字节数 | 规则 |
| --- | --- | --- |
| 无校验 | 0 | 跳过校验 |
| SUM8 | 1 | 覆盖字节累加，取低 8 位 |
| SUM16 | 2 | 覆盖字节累加，取低 16 位 |
| XOR8 | 1 | 覆盖字节逐个异或 |
| CRC-16/MODBUS | 2 | 初始 FFFF，反射实现多项式 A001，最终异或 0000 |

两字节结果可以选择大端或小端。覆盖起点包含该字节，覆盖终点不包含该字节；选择常用覆盖范围时自动取校验字节之前的位置；指定范围时负数从帧尾计数。起点 0 表示包含帧头，起点等于帧头字节数表示排除帧头。范围必须非空且不能包含校验结果本身。

在帧结构中添加多条独立校验部分，分别选择算法和覆盖范围。预设包含 SUM8／SUM16／XOR8、CRC-16/MODBUS、CRC-16/CCITT-FALSE、CRC-32/ISO-HDLC，以及 CRC-8/SMBUS、CRC-8/MAXIM-DOW。CRC-16/CCITT-FALSE 在界面标注其标准名称 CRC-16/IBM-3740。选择“自定义 CRC”时可填写 8/16/32 位宽、多项式、初值、输入／输出反转及最终异或值。主编辑页不再重复提供校验控件。

多项式统一输入标准形式：CRC16 的 0x1021 对应代码里的反射形式 0x8408，CRC8 的 0x31 对应 0x8C；不要在标准多项式一栏输入反射形式。机器人 CRC8 初值 FF，CRC16 初值 FFFF，均输入／输出反转、最终异或 0。MODBUS 则使用标准多项式 0x8005。

帧尾保留字节与是否验证分开：关闭一条规则只跳过校验，保留它占用的字节。要移除结果字节，请删除帧结构中的该校验部分。旧配置仍可读取原有宽度规则。

机器人模板先校验 5 字节固定头部，再信任长度字段；完整帧收齐后验证末尾 CRC16，再按命令号解析载荷。最多 8 条规则、16 字节显式帧尾和 16 种消息类型；校验范围不能包含自身结果。高级范围中，负偏移从整帧末尾计，覆盖终点不包含在范围内。

没有校验时无法保证任意噪声都能被识别为坏帧。

## 两个可直接尝试的例子

### 固定 float32

- 帧头 AA 55，固定总长 6，无校验。
- 字段 value：float32，小端，偏移 2，数量 1。
- 发送 `AA 55 00 00 C0 3F`，应显示 value = 1.5。

### 变长 float32 数组

- 帧头 AA 55，选择长度字段决定。
- 长度偏移 2、宽度 2、小端、表示数据区字节数；数据区起点 4。
- 无校验。
- 字段 samples：float32、小端、偏移 4，勾选“剩余数值数组（变长）”。
- 发送 `AA 55 08 00 00 00 C0 3F 00 00 00 C0`，应显示 `[1.5, -2]`。

若要显示原始字节，将该字段类型改为 bytes；例如 `AA 55 05 00 01 AA 55 FF 00` 会显示 5 个原始字节，数据区出现 AA 55 不会被当成新帧头。

## 实现边界与验证

协议目录、配置验证、CSV／键值文本／二进制解析器、协议会话分别独立，均在 `protocol_core` 中，只链接 Qt Core。应用装配层将同一个 ByteSource 分别连接到原始接收会话和协议会话。解析器增量消费字节，使用有上限的半帧缓存；协议会话只保留最新解析帧并以约 50 ms 合并界面通知。

测试覆盖 CRC 已知向量、文本分片和坏行、整数符号与浮点、大小端、所有长度规则、空数组、原始字节里的帧头、校验失败及坏长度后的重新同步、非法配置拒绝、配置保存，以及 PTY 真实串口路径到解析表／编辑器的集成。Windows 实际串口和不同固件协议仍需对应设备实测。

### 标准预设与旧配置兼容

校验菜单不提供工程专用 CRC8／CRC16 预设。CRC-8/SMBUS 使用 poly=0x07、init=0、refin/refout=false、xorout=0；CRC-8/MAXIM-DOW 使用 poly=0x31、init=0、refin/refout=true、xorout=0。机器人模板中 init=FF 的 CRC8 以及原 CRC16 以完整的自定义 CRC 参数保存。旧标识仅用于读取兼容，加载后转换为自定义 CRC，不改变实际算法。参考 CRC RevEng 参数目录 https://reveng.sourceforge.io/crc-catalogue/all.htm 。
